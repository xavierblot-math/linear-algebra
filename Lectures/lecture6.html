Lecture 6 : linear maps

Definition and first examples

Linear maps (also called morphisms or homomorphisms of vector spaces) are maps between vector spaces that respect addition and scalar multiplication.

Example

Define \(f:\mathbb R^2\to\mathbb R^2\), \((x,y)\mapsto (x+y,\;x-y)\). Then

\begin{equation*} \begin{split} f((x_1,y_1)+(x_2,y_2))=&f(x_{1}+x_{2},y_{1}+y_{2})\\ &=(x_{1}+x_{2}+y_{1}+y_{2},x_{1}+x_{2}-y_{1}-y_{2})\\ &=(x_{1}+y_{1},x_{1}-y_{1})+(x_{2}+y_{2},x_{2}-y_{2})=f(x_1,y_1)+f(x_2,y_2) \end{split} \end{equation*}

and similarly

\[ f(\lambda(x,y))=\lambda f(x,y). \]

By contrast, a map such as \(g(x,y)=(x^2\sin y,\;e^x-y)\) is far from respecting addition and multiplication by scalars..

Definition

Let \(E,F\) be vector spaces over \(\mathbb K\). A \(\mathbb K\)-linear map between $E$ and $F$ is a map \(f:E\to F\) such that

  1. \(f(u+v)=f(u)+f(v)\) for all \(u,v\in E\);
  2. \(f(\lambda u)=\lambda f(u)\) for all \(\lambda\in\mathbb K,\ u\in E\).

Equivalently, for all \(\lambda,\mu\in\mathbb K\) and \(u,v\in E\), \(f(\lambda u+\mu v)=\lambda f(u)+\mu f(v)\).

Here is a simple consequence of the linearity condition.

Lemma

Let \(f:E\to F\) be a linear map between vector spaces. Then \(f(0)=0\).

Proof

We simply observe that \(f(0)=f(0+0)=f(0)+f(0)\) implies \( f(0)=0\).

Examples

  1. Zero map. The zero map \(0:E\to F\) is defined by \(u\mapsto 0\). It is clearly linear.
  2. Identity map. The identity map of a vector space $E$, denoted by \(\mathrm{id}_E:E\to E\) or simply \(\mathrm{id}\), is defined by \(u\mapsto u\). It is clearly linear.
  3. Evaluation map. For a non-empty set \(X\), denote by \(\mathcal{F}(X,\mathbb{R})\) the space of real-valued functions on \(X\). Fix an element \(x_0\in X\). We define the evaluation map at $x_{0}$ by
    \begin{equation*} \begin{split} \mathrm{ev}_{x_0}:\mathcal{F}(X,\mathbb{R})&\longrightarrow\mathbb{R}\\ f&\longmapsto f(x_0). \end{split} \end{equation*}
    It is clearly $\mathbb{R}$-linear.
  4. Linear polynomials. For \(P\in\mathbb R[X]\), the induced map \(\mathbb R\to\mathbb R\), \(x\mapsto P(x)\), is linear if, and only if, \(\deg P=1\).

Notation / Definition

Let $E$ and $F$ be vector spaces over $\mathbb{K}$. Then \(\mathrm{Hom}_{\mathbb K}(E,F)\) (also \(\mathcal L_{\mathbb K}(E,F)\)) denotes the set of \(\mathbb K\)-linear maps \(E\to F\).

In the case \(E=F\), a linear map \(f:E\to E\) is called an endomorphism of $E$. We write \(\mathrm{End}_{\mathbb K}(E)=\mathrm{Hom}_{\mathbb K}(E,E)\).

Example
On \(\mathbb K[X]\), the derivative \(D:\mathbb K[X]\to\mathbb K[X]\), sending \(P(X)\) to the derivative \(P'(X)=\frac{d}{dX}P(X)\), is an endomorphism of $\mathbb{K}[X]$.

Linear maps can be added and multiplied by scalars, thus endowing the sets of linear maps with a structure of vector space.

Proposition

  1. If \(E,F\) are \(\mathbb K\)-vector spaces, then \(\mathrm{Hom}_{\mathbb K}(E,F)\) is a \(\mathbb K\)-vector space with \((f+g)(u)=f(u)+g(u)\), \((\lambda f)(u)=\lambda f(u)\), \(0(u)=0\).
  2. Composition of linear maps is linear: if \(f:E\to F\) and \(g:F\to G\) are linear, then \(g\circ f:E\to G\) is linear.
Proof

The first claim is left as an exercise. For the second claim, we have by the linearity of both $f$ and $g$

\[ g(f(u+v))=g(f(u)+f(v))=g(f(u))+g(f(v)) \]
so that $g\circ f$ preserves addition. Similarly \(g(f(\lambda u))=g(\lambda f(u))=\lambda\, g(f(u))\).

Notation

For \(f\in \mathrm{End}_{\mathbb K}(E)\), write \(f^{(k)}\) or \(f^k\) for the \(k\)-fold composition; in particular \(f^2=f\circ f\).

Image, kernel and isomorphisms

The structure of linear maps is such that vector subspace structures are preserved under set-theoretical image and pre-image.

Proposition

Let \(f:E\to F\) be linear between $\mathbb{K}$-vector spaces.

  1. If \(E'\subseteq E\) is a vector subspace, then \(f(E')=\{f(u')\mid u'\in E'\}\) is a vector subspace of \(F\).
  2. If \(F'\subseteq F\) is a vector subspace, then \(f^{-1}(F')=\{u\in E\mid f(u)\in F'\}\) is a vector subspace of \(E\).
Proof

For the first point, we first observe that since $0\in E'$ and then $0=f(0)\in f(E')$. Next, if $u,v\in f(E')$, by definition we can write $u=f(u')$ and $v=f(v')$, with $u',v'\in E'$. Since $f$ preserves addition, we have $u+v=f(u'+v')$. Because $E'$ is a vector subspace, $u'+v'\in E'$. We infer that $u+v\in f(E')$. Similarly with multiplication by scalars.

For the second point, because $f(0)=0\in F'$, we deduce that $0\in f^{-1}(F')$. Next, if $u,v\in f^{-1}(F')$, by definition this means that $f(u),f(v)\in F'$. Because $f$ is linear and $F'$ is closed under addition, we have $f(u+v)=f(u)+f(v)\in F'$, which means that $u+v\in f^{-1}(F')$. Similarly for multiplication by scalars.

Definition (Image and kernel)

Let $f\colon E\to F$ be a linear map between vector spaces.

  • The image of $f$ is the vector subspace $f(E)$ of $F$, and we denote it by $\mathrm{im}(f)$ or $\mathrm{Im}(f)$.
  • The kernel of $f$ is the vector subspace $f^{-1}(\lbrace 0\rbrace)$ of $E$, and we denote it by $\mathrm{ker}(f)$ or $\mathrm{Ker}(f)$.

Examples

  1. Evaluation at \(0\) on \(\mathbb K[X]\). Consider the evaluation map \[ \operatorname{ev}_0:\mathbb K[X]\longrightarrow\mathbb K,\qquad P\longmapsto P(0). \] Then \(\operatorname{Im}(\operatorname{ev}_0)=\mathbb K\) and \(\operatorname{Ker}(\operatorname{ev}_0)=\{P\in\mathbb K[X]\mid P(0)=0\}=X\cdot\mathbb K[X].\)
  2. A map to a product. Define a map \[ \Phi:\mathbb K[X]\longrightarrow \mathbb K[X]\times\mathbb K,\qquad P(X)\longmapsto\big(P'(X),\,P(2025)\big). \] This is clearly a linear map, since both the derivative map and the evaluation map are linear. We have \(\operatorname{Ker}\Phi=\{0\}\): if \(P'(X)=0\) then \(P\) is constant, and \(P(2025)=0\) implies this constant is $0$, hence \(P=0\). Moreover \(\operatorname{Im}\Phi=\mathbb K[X]\times\mathbb K\): given \((Q(X),\lambda)\), take \[ \widetilde P(X)=\sum_{k=0}^{n} a_k\frac{X^{k+1}}{k+1} \quad\text{if } Q(X)=\sum_{k=0}^{n} a_kX^k, \] and set \(P(X)=\widetilde P(X)+(\lambda-\widetilde P(2025))\). Then \(\Phi(P)=(Q,\lambda)\).

Definition (reminder)

Let $f\colon X\to Y$ be a map between two sets.

  • We say that $f$ is surjective if \(f(X)=Y\). That is, for every $y\in Y$, there exists $x\in X$ such that $f(x)=y$
  • We say that $f$ is injective if \(f(x_1)=f(x_2)\Rightarrow x_1=x_2\) Equivalently, \(x_{1}\ne x_{2} \Rightarrow f(x_1)\ne f(x_2)\).
  • We say that $f$ is bijective if $f$ is both surjective and injective. That is, for every $y\in Y$ there exists a unique $x\in X$ such that $f(x)=y$.

Proposition

Let $f\colon E\to F$ be a linear map. Then:

  1. \(f\) is surjective \(\iff\ \operatorname{Im}(f)=F\).
  2. \(f\) is injective \(\iff\ \operatorname{Ker}(f)=\{0\}\).
Proof

(a) is by definition of the image. For (b): if \(f\) injective and \(f(u)=0=f(0)\), then \(u=0\). Conversely, if \(\operatorname{Ker} f=\{0\}\) and \(f(u)=f(v)\), then \(f(u-v)=0\), hence $u-v$ is in the kernel and \(u-v=0\), i.e. \(u=v\).

Definition (Isomorphism/Automorphism)

A linear map \(f:E\to F\) is an isomorphism if it is bijective. If moreover \(E=F\), then we say it is an automorphism of $E$.

Examples
  1. The derivative \(D=d/dX:\mathbb K[X]\to\mathbb K[X]\) is not an automorphism since its kernel is the space of constant polynomials, which is not $\lbrace 0\rbrace$.
  2. The map $\Phi\colon \mathbb{K}[X]\to \mathbb{K}[X]\times\mathbb{K}$ sending $P(X)$ to $(P'(X),P(2025))$ is an isomorphism. Indeed, in the examples above we showed that the kernel is trivial and that $\Phi$ is surjective.

Proposition

Let \(f:E\to F\) be an isomorphism of \(\mathbb K\)-vector spaces. Then the inverse map inverse \(f^{-1}:F\to E\) is \(\mathbb K\)-linear (hence an isomorphism).

Proof

For \(v_1,v_2\in F\), let \(u_i=f^{-1}(v_i)\) the unique pre-image of $v_{i}$, so that in particular $f(u_i)=v_{i}$. Then by linearity of \(f\) we have \(f(u_1+u_2)=v_1+v_2\), and by the bijectivity \(f^{-1}(v_1+v_2)=u_1+u_2=f^{-1}(v_1)+f^{-1}(v_2)\). Similarly, \(f^{-1}(\lambda v)=\lambda f^{-1}(v)\) for \(\lambda\in\mathbb K\).

Basic constructions of linear maps

We discuss some basic constructions with linear maps yielding linear maps.
Some basic constructions
  • Restriction. Let $f\colon E\to F$ be a linear map, and $E'\subseteq E$ a vector subspace. Then the restriction of $f$ to $E'$, namely $f|_{E'}\colon E'\to E$ is a linear map. It satisfies $\operatorname{Im}(f|_{E'})=f(E')$ and $\operatorname{Ker}(f|_{E'})=\operatorname{Ker}(f)\cap E'$.
  • Extension. Let $E$ be a vector space, and $E'$ a vector subspace. Let $f\colon E'\to F$ be a linear map. Then, there exists a linear map $\widetilde{f}\colon E\to F$ such that $\widetilde{f}|_{E'}=f$. Indeed, let us choose a complement $E''$ of $E'$, so that we can decompose $E=E'\oplus E''$. We define $\widetilde{f}\colon E\to F$ by the rule $\widetilde{f}(e)=f(e')$, where $e'$ is given by the decomposition $e=e'+e''$ according to $E=E'\oplus E''$. This is a linear map. The extension $\widetilde{f}$ so-defined satisfies $\operatorname{Im}(\widetilde{f})=\operatorname{Im}(f)$, and $\operatorname{Ker}(\widetilde{f})=\operatorname{Ker}(f)\oplus E''$. Note that $\widetilde{f}$ is not unique.
  • Gluing. Let $E$ a vector space, and assume $E=E'\oplus E''$ and we are given linear maps $f'\colon E'\to F$ and $f''\colon E''\to F$. Then we can define a linear map $f\colon E\to F$ by $f(e)=f'(e')+f''(e'')$, where $e=e'+e''$ is the decomposition of $e$ according to $E=E'\oplus E''$. The restriction of $f$ to $E'$ (resp. $E''$) coincides with $f'$ (resp. $f''$). The image of $f$ coincides with $\operatorname{Im}(f')+\operatorname{Im}(f'')$, but note there is no reason this should be direct sum.
