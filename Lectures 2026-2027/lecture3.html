Lecture 3 : dimension and linear independence

In the last lecture, we studied basic constructions with vector subspaces, including the span of a family of vectors. In this lecture, we use the latter in order to introduce the notion of finite dimensional vector space. This naturally leads us to linear independence of vectors.

Dimension

Definition

Let \(E\) be a \(\mathbb K\)-vector space. We say that \(E\) is finite dimensional if there exists a finite set of vectors \(e_1,\dots,e_n\) such that \(E=\langle e_1,\dots,e_n\rangle\). In this case, we define

\[ \dim E=\min\{\,\#A \mid A\subset E \text{ finite and } E=\langle A\rangle \,\}. \] Otherwise, \(E\) is infinite dimensional and we write \(\dim E=+\infty\).

Convention/Fact
  • If \(E=\{0\}\), then \(E=\langle\varnothing\rangle\) and \(\dim E=0\).
  • Conversely, if \(\dim E=0\), then \(E=\{0\}\).
Examples
  1. \(\mathbb{R}^2=\langle (1,0),(0,1)\rangle\), hence \(\dim\mathbb{R}^2\le 2\). Since \(\mathbb{R}^2\ne\{0\}\), we get \(\dim\mathbb{R}^2\ge1\). It cannot be \(1\). Otherwise \(\mathbb{R}^2=\langle e\rangle\), which would imply that for some \(\lambda,\mu\in\mathbb{R}\setminus\lbrace 0\rbrace\) we would have \[ (1,0)=\lambda e,\quad (0,1)=\mu e. \] From this it follows that \[ (1,0)=\frac{\lambda}{\mu}(0,1), \] which is absurd. Thus \(\dim\mathbb{R}^2=2\).
  2. \(\mathbb K[X]\) is infinite dimensional. Indeed, assume for contradiction that \(\mathbb K[X]=\langle P_1,\dots,P_n\rangle\) for some polynomials $P_1,\ldots,P_n$. There exists an integer $d\geq 0$ such that \(\deg P_i < d\) for all the $P_{i}$. Then \(X^d\) can not be written as \(\lambda_1 P_1+\cdots+\lambda_n P_n \), since in this expression all the monomials have degree strictly less than $d$.

Linear independence

Definition

Let $E$ be a vector space and \(u_1,\dots,u_n\in E\). We say that these vectors are linearly independent if \[ \lambda_1u_1+\cdots+\lambda_nu_n=0 \ \Rightarrow\ \lambda_1=\cdots=\lambda_n=0 \] for \(\lambda_i\in\mathbb K\). More generally, a family \((u_i)_{i\in I}\) is linearly independent if every finite subfamily is linearly independent.

Remark

A vector $u\in E$ is linearly independent if, and only if, $u\neq 0$.

Pictures
\(\mathbb{R}^2\): two non-collinear vectors are linearly independent.
\(\mathbb{R}^3\): three vectors are linearly independent if no two are collinear and they are not contained in the same plane.
Lemma

Let \(E\) be a \(\mathbb K\)-vector space and \(u_1,\dots,u_n\in E\). The following are equivalent:

  1. \(u_1,\dots,u_n\) are linearly independent.
  2. Every \(u\in\langle u_1,\dots,u_n\rangle\) has a unique representation \(u=\lambda_1u_1+\cdots+\lambda_nu_n\) with \(\lambda_i\in\mathbb K\).
Proof

(a)\(\Rightarrow\)(b): If \(u=\mu_1u_1+\cdots+\mu_nu_n=\lambda_1u_1+\cdots+\lambda_nu_n\), subtract and use (a) to get \(\mu_i=\lambda_i\) for all \(i\).

(b)\(\Rightarrow\)(a): If \(\lambda_1u_1+\cdots+\lambda_nu_n=0\), compare with the trivial representation \(0=0\cdot u_1+\cdots+0\cdot u_n\) and use uniqueness.

Examples
  1. In $\mathbb{K}^{n}$, the vectors $(1,0,\ldots, 0), (0,1,0,\ldots,0),\ldots, (0,0,\ldots, 1)$ are linearly independent.
  2. In \(\mathbb K[X]\), the polynomials \(1,X,X^2,\dots\) are linearly independent.
  3. Let \(E=\mathcal{F}(\mathbb{R},\mathbb{R})=\{f:\mathbb{R}\to\mathbb{R}\}\) the space of functions on $\mathbb{R}$ with real values. For \(\lambda\in\mathbb{R}\), set \(f_\lambda(x)=e^{\lambda x}\). The family \(\{f_\lambda\}_{\lambda\in\mathbb{R}}\) is linearly independent. Indeed, suppose that for some distinct real numbers $\lambda_{1},\ldots,\lambda_{n}$ there exists a relationship \[ \alpha_1 e^{\lambda_1 x}+\cdots +\alpha_{n} e^{\lambda_n x}=0,\quad\text{for all }x\in\mathbb{R}. \] Without loss of generality we may assume \(\lambda_1<\cdots<\lambda_n\). Then, dividing by \(e^{\lambda_n x}\) we obtain \[ \alpha_1 e^{(\lambda_1-\lambda_n ) x}+\cdots +\alpha_{n-1} e^{(\lambda_{n-1}-\lambda_{n}) x}+\alpha_{n}=0,\quad\text{for all }x\in\mathbb{R}. \] We let $x\to+\infty$, and because $\lambda_{i}-\lambda_{n}<0$ for all $i\leq n-1$, we get \(\alpha_n=0\). Iterating this reasoning we see that all the coefficients $\alpha_{i}$ vanish.
Lemma

If \(A=\{u_i\}_{i\in I}\) is linearly independent and \(B=\{u_j\}_{j\in J}\subset A\) is a subfamily \((J\subset I\)), then \(B\) is linearly independent.

Proof

Immediate by restriction to finite subfamilies.

Proposition

Let \(E\) be a finite dimensional \(\mathbb K\)-vector space and suppose \(\dim E=n\). If \(E=\langle e_1,\dots,e_n\rangle\), then the vectors \(e_1,\dots,e_n\) are linearly independent.

Proof

Suppose for contradiction that the vectors are not linearly independent. Then, there exists a non-trivial linear relationship \[ \lambda_{1}e_{1}+\ldots+\lambda_{n}e_{n}=0. \] Here, non-trivial means that some of the coefficients $\lambda_{i}$ is not zero. Without loss of generality we may assume that $\lambda_{1}\neq 0$. Then, rearranging we find \[ e_{1}=-\frac{\lambda_{2}}{\lambda_{1}}e_{2}-\cdots-\frac{\lambda_{n}}{\lambda_{1}}e_{n}. \] This means that $e_{1}$ can be disregarded in the span $\langle e_{1},\ldots,e_{n}\rangle$, since it can be obtained as a combination of the other vectors. Therefore, we see that $E=\langle e_{2},\ldots, e_{n}\rangle$, which in turn entails that $\dim E\leq n-1$, contradicting $\dim E=n$.

Linear dependence

Definition

We say that a collection of vectors $u_{1},\ldots, u_{n}$ in a vector space is linearly dependent if it is not linearly independent. Namely, there exist a non-trivial relationship \[ \lambda_{1}u_{1}+\cdots+\lambda_{n}u_{n}=0. \] We similarly define linear dependence of an arbitrary family of vectors, possibly infinite.

Lemma

A family $u_{1},\ldots, u_{n}$ is linearly dependent if, and only if, for some $i\in\lbrace 1,\ldots,n\rbrace$ we have \[ \langle u_{1},\ldots,u_{i-1},u_{i+1},\ldots, u_{n}\rangle=\langle u_{1},\ldots, u_{n}\rangle. \] That is, we can disregard some vector without changing the span.

Proof

Similar to the previous proposition.
